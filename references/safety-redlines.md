# 防封号操作红线 v0｜获客红队

> 原则：**安全 > 速度**。试跑标「内部学习验证」；商用授权另排。  
> 适用：小红书 MediaCrawler 试跑与后续扩量；抖音等同理从严。  
> 拍板：获客领航｜起草：守界｜2026-09-29

---

## 0. 一句话

低频、小批量、人工过验证、遇阻即停；不做绕过、不私信、不外传原始 CSV。

---

## 1. 频率与规模上限（硬上限，未经领航书面放宽禁止突破）

| 项 | 试跑硬上限 | 说明 |
|----|------------|------|
| 并发 `MAX_CONCURRENCY_NUM` | **1** | 禁止调高 |
| 请求间隔 `CRAWLER_MAX_SLEEP_SEC` | **≥ 3s**（建议 3～5） | 禁止为提速压到 &lt;2s |
| 关键词数 / 日 | **≤ 3**（第一刀） | 扩到 12 词须领航拍板且分日切 |
| 每词笔记上限（有效） | **≤ 5** | 见 §2：配置值≠真实拉取时以真实为准 |
| 单帖一级评论 | **≤ 5** | 扩到 10 须拍板 |
| 二级评论 | **关** | 默认禁止开 |
| 媒体下载 / 词云 | **关** | |
| IP 代理 | **关** | 禁止用代理绕过风控 |
| 日会话次数 | **≤ 2 次**小切片 | 两次之间冷却 ≥ 30 分钟 |
| 日笔记详情合计（估） | **≤ 30** | 含搜索页误拉；超了当日停 |
| 日评论合计（估） | **≤ 50** | 超了当日停 |

**日配额心智**：一天只验链路，不追求覆盖；宁缺样例，不赌号。

---

## 2. 配置必须「真限制」（本次事故吸取）

2026-09-29 试跑：`CRAWLER_MAX_NOTES_COUNT=5` **未挡住**搜索页批量，实际拉了 **20** 帖详情 → 采核已急停。

**红线**：

1. 开跑前必须用空跑/日志确认：**实际详情请求数 ≤ 配置上限**。
2. 若搜索列表会预拉多页：须改代码/参数逻辑（截断列表、提前 `break`、或降搜索页大小），**未修前禁止再开全自动切片**。
3. 跑中盯日志：单关键词详情 &gt; 5 或总详情突发飙升 → **立即停进程**并 @获客领航 @守界。

---

## 3. 遇滑块 / 验证 / 限流 —— 停手规程

| 现象 | 动作 | 禁止 |
|------|------|------|
| 滑块、验证码、人机 | **立刻停**（SIGTERM 进程）；保留现场给领航 | 自动点、刷、脚本过验证、找「过码」服务 |
| 登录失效 / 扫码过期 | 停；冷却后再扫 | 狂刷二维码、多开扫 |
| 429 / 频繁操作 / 空结果异常 | 停；当日不再采该号 | 换代理硬闯、降间隔重试 |
| 账号异常提示、强制改密 | **停用该号**；换隔离号或改日 | 继续采 |

冷却建议：滑块/限流后 **≥ 2 小时**；当日第二次仍触发 → **封当天**，次日再评估。

---

## 4. 账号隔离

1. **试跑号 ≠ 主号 / 商用号**；能隔离就隔离。
2. 一机一号一 Chrome 用户数据目录；禁止多账号同浏览器配置乱切。
3. `SAVE_LOGIN_STATE` 可开以减少重复扫码，但登录态文件 **不外传、不进 git**。
4. 封禁/强风控号：标记废弃，不用于扩量。

---

## 5. 禁止项（零例外）

- 绕过滑块 / 风控 / 签名校验（含任何 exploit、黑产过码）
- Cookie 盗用、撞库、买号批量登
- 自动私信、加微、群发、定向骚扰
- 非公开内容、需权限才能看的数据
- 开代理/指纹浏览器专门为「躲封」
- 一次拉满 12 词或并发 &gt;1 狂刷
- 原始含昵称 / 含 `xsec_token` 的 CSV **外传**（邮件、网盘公开链、群外）
- 高意向未人工抽检就触达
- 在 NCAL 许可未解决前，把本链路当商用获客正式产能

---

## 6. 数据与触达（与池栈/识需对齐）

- 原始 CSV：仅 `获客自动化/` 树内；入库前剥 `xsec_token`
- `nickname`：抽检/去重用，禁止外传原始包
- 留存：raw 30 天；excluded 14 天；ready / needs_review 暂不清
- `ready`：人工抽检 ≥30 条（或本批全量若 &lt;30）通过后，才谈触达；触达方案另批

---

## 7. 开跑检查单（每次启动前）

- [ ] 参数：并发 1、间隔 ≥3s、词 ≤3、评 ≤5、二级关、代理关、媒体关
- [ ] 已确认「搜索页批量」不会超过笔记上限（或已打补丁）
- [ ] 使用隔离号；扫码窗口有人值守
- [ ] 日志/PID 可随时 SIGTERM
- [ ] 产物路径在项目根内；不打算外传

开跑后：有人盯前 3 分钟日志；异常即停。
