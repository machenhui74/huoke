# 台州椒江地理词表 v0

用途：通用教育切片之外的「椒江本地」切片；内部学习验证。  
原则：地名搜词 + 评论地名加分；**不用机器 IP 伪装本地**；评论 IP 属地最多到省，仅辅助。

---

## 1. 目标区域

| 字段 | 值 |
|------|-----|
| target_region | 椒江 |
| 上级 | 台州市 · 浙江省 |
| 同城关联区 | 椒江、路桥、黄岩（台州主城区三角） |

---

## 2. 搜词列表（笔记搜索，椒江切片）

格式：`地名 + 教育品类`。第一刀只用 **3 个**，勿一次上满。

### 2.1 第一刀（建议）

```
椒江幼小衔接,椒江托管班,台州少儿编程
```

### 2.2 备选池（领航/采核按日配额轮换，日≤3 词）

```
椒江兴趣班,椒江英语启蒙,椒江钢琴班,椒江暑假班,椒江补习班,
台州托管班,台州幼小衔接,台州兴趣班推荐,路桥托管班,黄岩兴趣班,
椒江数学思维,椒江作文辅导,台州择校
```

说明：优先「椒江+品类」；流量不够再试「台州+品类」。不单搜裸「椒江」（噪音大）。

---

## 3. 评论地名命中（加分）

命中下列任一词 → **geo_hit=true**，`target_region` 取最细命中（椒江 > 路桥/黄岩 > 台州）。

| 层级 | 词（可改） | 加分 |
|------|------------|------|
| 核心 | 椒江、椒江区 | +20 |
| 主城 | 路桥、黄岩 | +12 |
| 市 | 台州、台州市 | +8 |
| 街道/地标（椒江侧，可续补） | 白云、章安、前所、下陈、洪家、葭沚、外沙、三甲 | +15（须同时有教育意向词，否则只标 geo、不加满） |
| 辅助排除 | 杭州、宁波、温州、上海、北京 等明确外市 | geo_hit=false；跨市噪音，意向分不因地理抬 |

与意向分叠加：`intent_score` 仍按原规则；地理分为独立字段或并入总分时 **上限 +20**，避免纯地名灌水。

建议写入 leads：

| 字段 | 说明 |
|------|------|
| geo_hit | true/false |
| target_region | 椒江 / 路桥 / 黄岩 / 台州 / （空） |
| geo_evidence | 命中的地名片段 |

---

## 4. IP 属地（仅辅助，不主判）

| 条件 | 处理 |
|------|------|
| 评论 IP 属地 = 浙江 | 辅助加分 **+3**（可选）；不能单独让低意向变 ready |
| 属地 ≠ 浙江 且评论无本地地名 | 不因地理加分；意向规则照常 |
| 无 IP 字段 | 忽略，不惩罚 |

**禁止**：用代理把爬虫伪装成台州/椒江 IP；地理精准只靠搜词与评论文本。

---

## 5. 分流（椒江切片）

在原有 ready / needs_review / excluded 之上：

- `geo_hit=true` 且 `intent_score≥70` → ready（仍人工抽检后触达）
- `geo_hit=true` 且 `40≤score<70` → needs_review（优先于无地理的中意向）
- `geo_hit=false` → 可入通用池或低优先级，不标 target_region=椒江

---

## 6. 给采核 / 池栈

- 采核：KEYWORDS 用 §2.1；规模仍 3 词×≤5 帖×≤5 评；截断补丁未证前不开跑。
- 池栈：leads 增加 `geo_hit` / `target_region` / `geo_evidence`（可空）。
- 词表可改，不锁死。
