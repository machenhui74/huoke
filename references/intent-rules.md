## 1. 搜词列表（笔记搜索）

幼小衔接、择校、暑假班、托管班、兴趣班推荐、数学思维、英语启蒙、钢琴班、编程课孩子、补习班避雷、少儿编程、作文辅导

## 2. 意向关键词与打分

**公式**：`意向分 = clamp(0,100, 基础分 + 加分 − 扣分)`  
有家长身份词才计全额；否则 ×0.6。

### 高意向（命中任一条 → 基础分 70）

| 类型 | 关键词 |
|------|--------|
| 求推荐 | 求推荐、求安利、哪家好、有没有靠谱、求问、求避雷后的推荐 |
| 要报名 | 想报、准备报、打算报、想给孩子报、准备给娃报、考虑报名 |
| 要联系 | 怎么报名、地址在哪、还有名额吗、能试听吗、多少钱一节 |

### 中意向（命中 → 基础分 45；可与高意向叠加取高）

| 类型 | 关键词 |
|------|--------|
| 纠结对比 | 纠结、A还是B、哪家靠谱一点、值得报吗 |
| 品类锚定 | 幼小衔接、择校、暑假班、托管班、兴趣班、数学思维、英语启蒙、钢琴、编程、补习、作文辅导、少儿编程 |
| 时间窗 | 暑假、开学前、这个月、马上、下周 |

### 咨询问句（家长在问，但还没说想报）

命中「家长身份 + 年龄或怎么办」且原分低于复核线时，抬到 **48**，`needs_review`。不因此变成 `ready`。

例：`2岁的娃合适吗`（适龄）。6 岁及以下没写「娃」但在问能不能上、多少钱、怎么报名（如 `8个月可以吗`、`2岁什么价格`、`怎么收费`）同样进复核。吐槽「收费怎么也得」不抬。机构口吻（暖到心坎、招生活动、赞助）不抬。裸「家长」二字（面向家长、被家长）不算评论者本人。投诉避雷仍可进复核，问题标成投诉，供人剔掉。

特殊需求（感统、注意力、多动、学障）命中后分数上限 **65**，只进复核。

### 低意向（命中 → 基础分 20）

| 类型 | 关键词 |
|------|--------|
| 围观 | 了解一下、看看、收藏、先记着 |
| 弱吐槽 | 好贵、好卷、没必要（无行动词） |

### 加分 / 扣分

| 规则 | 条件 | 分值 |
|------|------|------|
| +家长 | 我家孩子/娃/儿子/女儿/宝妈/宝爸 | +10 |
| +地点 | 某区、附近、同城、地铁站 | +8 |
| +预算 | 多少钱、学费、一节课、包月 | +10 |
| +紧迫 | 急、赶紧、暑假前必须 | +10 |
| −纯吐槽 | 有情绪无行动且无求推荐 | −15 |
| −学生腔 | 明显学生本人、无家长词 | −20 |

### 分流

| 意向分 | 标签建议 | 处理 |
|--------|----------|------|
| ≥70 | 高意向 | 入线索池 ready |
| 40–69 | 中意向 | needs_review |
| <40 | 低意向 | 不入池 / 归档 |

主标签：从搜词/品类词取一个（如 `少儿编程`、`择校`）；可多标签，逗号分隔。

## 3. leads 字段（试跑最小集）

| 字段 | 必填 | 说明 |
|------|------|------|
| comment_text | ✓ | 评论原文 |
| post_url | ✓ | 帖子/笔记 URL |
| nickname | ✓ | 评论者昵称 |
| commented_at | ✓ | 评论时间 |
| intent_score | ✓ | 0–100 |
| tags | ✓ | 如 `高意向,少儿编程,求推荐` |
| search_keyword | 建议 | 命中哪条搜词进的帖 |
| exclude_reason | 条件 | 淘汰时填写 |
| status | ✓ | ready / needs_review / excluded |

---

## 4. 明确排除词（命中 → status=excluded，不入池）

**广告 / 招生话术**  
私信领取、私信我、名额有限、火热报名、免费领资料、课程顾问、欢迎咨询、加微信、VX、威信、本机构、我司、招生中、试听名额

**机构互推 / 同行**  
同行交流、互推、换量、招生老师、我们机构也做

**无效**  
已报满晒单且无新需求；纯表情/单字；重复刷屏同一招生文

---

## 5. 试跑验收（给采核/池栈）

1. 用 §1 搜词采评论 → 按 §2 打分 → 填 §3 字段  
2. 抽 30 条人工看：高意向准确率、排除误杀率  
3. 词表有误直接改本文件，阈值可改，不锁死

## 6. 与 MediaCrawler 导出字段对照（试跑）

评论 CSV：`data/xhs/csv/search_comments_日期.csv`  
笔记 CSV：`data/xhs/csv/search_contents_日期.csv`（用 `note_id` 关联拿 `note_url` / `source_keyword`）

| leads 字段 | 来源 |
|------------|------|
| comment_text | comments.`content` |
| post_url | contents.`note_url`（via `note_id`） |
| nickname | comments.`nickname` |
| commented_at | comments.`create_time` |
| search_keyword | contents.`source_keyword`（或笔记侧） |
| intent_score / tags / status / exclude_reason | 识需规则打分写入 |

打分输入优先用 `content`；无家长词按规则 ×0.6。
