# ready 人工触达｜话术模板 + 企微活码流程 v0

原则：**合规第一**。只处理抽检通过的 `ready`；**人工发送**；禁止批量主动私信、禁止假种草评论、禁止未同意收集手机/微信号。

适用：小红书（抖音／视频号同思路，平台话术略改）。

## 1. 前置准备（一次性）

1. 企业微信建「获客-小红书」活码（或渠道活码），建议按来源拆：
   - `xhs-jiaojiang`（椒江）
   - `xhs-edu-general`（通用教育）
2. 活码设置：自动通过好友、欢迎语、自动标签（来源=小红书、区域、品类）。
3. 准备落地页／资料（PDF／试听说明）——私信里先给价值，再给码。
4. 池栈字段（建议）：`reach_status` / `reach_channel` / `wecom_qr_id` / `reach_note` / `reached_at`

`reach_status` 枚举：`pending_review` → `approved` → `commented` → `dm_sent` → `wecom_added` → `rejected` / `skipped`

## 2. 每日操作流程（人工）

1. 打开抽检清单（如 `池栈/data/leads_ready_review_*.csv`）。
2. **抽检**：看原文是否真实家长需求、是否本地相关、是否广告互推。不通过 → `rejected`，不触达。
3. 通过 → `approved`，选一条路径（优先从上到下）：

| 优先级 | 路径 | 何时用 |
|--------|------|--------|
| A | 公开评论友好回复 | 对方在公开评论区提问，适合先露脸建立信任 |
| B | 私信（对方曾互动／你已回复评论后） | 需要发资料／活码；勿对陌生人冷私信轰炸 |
| C | 仅记录、暂不触达 | 意向高但语境敏感／投诉贴／无合适开口 |

4. 触达后立刻改状态、记 `wecom_qr_id`、一句 `reach_note`。
5. 对方加企微后打标签，进入私域话术（另表），**本文件只管建联前**。

## 3. 话术模板（可改，保持真人语气）

### A. 公开评论回复（不塞微信号）

**问价类**（例：多少钱／什么价位）  
> 价位确实差挺多，和班型／课时有关。我整理过一份常见区间和避坑要点，评论区放不下，需要的话我私信你一份？

**纠结要不要报**  
> 理解，报班前纠结很正常。关键看孩子适不适应＋试听体验。我有一份「报名前 5 问」自评表，要的话我私信发你，你自己对照就行。

**求推荐／求靠谱**  
> 本地口碑差很多，别只看广告。我按「师资／班型／退费」列了个简单对照，评论区放不下，私信我「对照表」我发你。

**禁止**：假装自己孩子上过某机构的虚假经历；评论区直接留微信号／手机号；复制粘贴同一句刷多帖。

### B. 私信（评论回复之后，或对方先私信你）

**开场（带资料）**  
> 你好，我是看了你在「{笔记主题}」下的留言才联系的。按你问的「{对方原话关键词}」，先发你这份简短说明（无推销）：{资料名}。  
> 若还想一对一问本地班型，可以扫这个企微活码，备注「小红书-{关键词}」，我按备注给你对接：{活码图片或短链}

**对方冷淡／已解决**  
> 好的，不打扰了。资料你先留着，以后需要再找我～

**禁止**：未互动就群发；一天对同一人连发多条；话术里写「加我送优惠」类诱导违规表述（按平台当期规则再审）。

### C. 企微通过后欢迎语（配在活码里）

> 你好，我是{称呼}。你从「小红书」过来的对吧？先告诉我：孩子大概年级＋最关心的是（提分／托管／兴趣／幼小衔接）哪一块，我按你的情况回，不群发广告。

## 4. 对照今早椒江 2 条 ready（示例用法）

1. 「3周岁娃什么价位」→ 路径 A 问价模板 → 同意后再 B 发资料+`xhs-jiaojiang` 活码。  
2. 「纠结要不要报名」→ 路径 A 纠结模板 → 再 B。  

两条均**无 geo**：开口不要硬说「椒江」；若对方提到台州／椒江再切本地话术。

---

## 5. 守界红线（触达段）

- 只触达 `approved`；本批 ready 全抽检。  
- 不自动发评／不自动私信／不互关机器人。  
- 不收集对方未主动提供的手机／微信号。  
- 活码与话术不承诺绝对效果、不贬低竞品造谣。  
- 教育类注意未成年人相关表述，不诱导过度焦虑。
- **禁假种草**：勿写未核实的「我家娃／同龄娃也…」经历；开口用中性表述。
- **禁冷私信**：须先有公开评论互动或对方先私信；陌生人直接私信＝禁止。
- **禁批量**：同一话术勿刷多帖；单日主动触达建议 ≤5 条，且条条手改关键词。
- **活码**：`PLACEHOLDER_*` 真码替换前不对外发图／短链；未 `approved` 不进 B 路径。
